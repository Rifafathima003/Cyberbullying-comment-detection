# Cyberbullying-comment-detection
Machine learning  project to detect cyberbullying in YouTube comments using NLP and SVM.

This project detects cyberbullying in YouTube comments using Natural Language Processing and Machine Learning.

🚀 Features:

  ✔ Text preprocessing with emoji handling
  
  ✔ TF-IDF feature extraction
  
  ✔ Multiple ML models (LR, NB, RF, SVM)
  
  ✔ Best accuracy: 83% using SVM
  
  ✔ Real-time comment prediction
  

🧠 Technologies Used:

    Python
    
    Scikit-learn
    
    NLTK
    
    Pandas
    
    NLP techniques
    

📊 Models Compared:

    Logistic Regression
    
    Naive Bayes
    
    Random Forest
    
    Support Vector Machine (Best)
    

📈 Results:

  SVM achieved the highest accuracy in detecting cyberbullying comments.

📌 Future Improvements:

  Deep learning (BERT/LSTM)
  
  Multilingual support
  
  Real-time monitoring system
